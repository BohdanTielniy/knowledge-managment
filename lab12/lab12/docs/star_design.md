# Результат 1. Проєктування зіркової схеми OLAP-куба (Domain Knowledge Hub)

## 1. Бізнес-процес і зерно факту (C1)
- **Предметна область**: Довкілля — «Управління лісовими продуктами» (лісництва `LS-01`–`LS-04`, виділи `V-001`–`V-206`, таксономія продуктів із ЛР 5).
- **Бізнес-процес**: Облік операцій заготівлі деревинних та збору недеревинних лісових продуктів із контролем екологічних обмежень (річний приріст, квоти, сертифікація FSC, індекс NDVI).
- **Зерно факту (`fact_forest_harvest`)**: **1 рядок = 1 задокументована подія заготівлі або збору одного лісового продукту (ідентифікованого за IRI таксономії) на конкретному лісовому виділі в конкретну дату конкретним виконавцем за одним дозволом**.

## 2. Бізнес-питання (≥ 5)
1. **Q1**: Яка динаміка обсягів заготівлі деревини (м³) та виручки (грн) у розрізі років, кварталів і лісництв?
2. **Q2**: Як розподіляються виручка, маржа та фізичні обсяги вздовж ієрархії таксономії продуктів (`Клас → Підклас → Продукт`)?
3. **Q3**: Яка структура виручки за лісництвами у розрізі кварталів (матриця pivot) та як змінюється 3-місячна ковзна середня виручки?
4. **Q4**: Яка частка виручки та обсягів припадає на FSC-сертифіковані виділи та як змінюється показник по лісництвах?
5. **Q5**: Які виконавці (лісники й бригади) займають перші позиції за виручкою у кожному лісництві?
6. **Q6**: Як сезонні чинники та пожежонебезпечний період впливають на заготівлю деревини й збір недеревинних продуктів (гриби, ягоди, лікарські рослини)?

## 3. Виміри, ієрархії та політика SCD (C2)

| Вимір | Ієрархія | Використання таксономії / IRI | Політика SCD |
|---|---|---|---|
| `dim_date` | `year → quarter → month → full_date` (+ `season`) | — | Статичний (Type 0) |
| `dim_product_taxonomy` | `top_class_uk → subclass_uk → product_name_uk` | **Так** (`product_iri`, `parent_iri`, `skos_notation` із ЛР 5, простір `https://foresthub.ua/onto/`) | **SCD Type 1** (виправлення назв і базових цін без дублювання версій) |
| `dim_location` | `region_name → forestry_code → compartment_code` | Коди виділів та лісництв із ЛР 7–11 | **SCD Type 2** (`valid_from`, `valid_to`, `is_current` — історія зміни статусу FSC та NDVI-діапазону) |
| `dim_actor` | `actor_type → forestry_code → staff_code` | Виконавці з ЛР 9–11 | **SCD Type 2** (переведення між лісництвами) + Type 1 для описок у ПІБ |
| `dim_permit` | `permit_type → eco_risk_level → permit_code` | Типи дозволів із ЛР 9–11 | **SCD Type 1** (оновлення параметрів квоти) |

## 4. Класифікація мір (C3)

| Тип міри | Стовпці факту | Правило агрегації |
|---|---|---|
| **Адитивні** | `volume_m3`, `mass_kg`, `revenue_uah`, `cost_uah`, `margin_uah`, `event_count` | Сумуються (`SUM`) за всіма вимірами без обмежень |
| **Напівадитивні** | `remaining_quota_m3`, `standing_stock_m3` | Сумуються по простору (`dim_location`), але **не сумуються по часу** (беруться на останню дату / `AVG`/`MIN`) |
| **Неадитивні** | `unit_price_uah`, `margin_pct`, `damaged_trees_share_pct`, `ndvi_score` | Не можна сумувати; перераховуються як відношення сум (`SUM(margin_uah)/SUM(revenue_uah)`) або зважене середнє |

## 5. Діаграма зіркової схеми (C4)

Візуальна схема збережена у `docs/fig_star_schema.png`.

```
                  +-------------------------+
                  |        dim_date         |
                  | PK date_sk              |
                  | year -> quarter -> date |
                  +------------+------------+
                               |
+------------------------+     |     +---------------------------+
|  dim_product_taxonomy  |     |     |       dim_location        |
| PK product_sk          |     |     | PK location_sk (SCD2)     |
| product_iri (ЛР5 IRI)  +-----+-----+ region -> forestry ->     |
| top_class -> subclass  |     |     | compartment (V-001..V-206)|
+------------------------+     |     +---------------------------+
                               |
                  +------------+------------+
                  |   fact_forest_harvest   |
                  | PK fact_id              |
                  | FK date_sk, product_sk  |
                  | FK location_sk, actor_sk|
                  | FK permit_sk            |
                  | Measures: volume_m3,    |
                  | mass_kg, revenue_uah,   |
                  | margin_uah, margin_pct  |
                  +------+-----------+------+
                         |           |
       +-----------------+           +------------------+
       |                                                |
+------+----------------+                     +---------+-----------+
|       dim_actor       |                     |     dim_permit      |
| PK actor_sk (SCD2)    |                     | PK permit_sk (SCD1) |
| actor_type -> staff   |                     | permit_type -> code |
+-----------------------+                     +---------------------+
```
