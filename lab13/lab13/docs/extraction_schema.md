# Результат 1. Схема витягу знань та інструкція розмітки (Domain Knowledge Hub)

## 1. Типи сутностей (6 типів, C1)

| Тип | Визначення | Приклади | Контрприклади |
|---|---|---|---|
| `FORESTRY` | Організаційна одиниця — лісництво | `LS-01` («Карпатське»), `LS-02` («Бескидське») | «Карпати» (гірський масив), «Львівщина» |
| `COMPARTMENT` | Таксаційний лісовий виділ | `V-003`, `V-012`, `V-102`, `V-204` | «№102» (номер наказу), «кв. 3» без коду виділу |
| `SPECIES` | Лісотвірна деревна порода | `ялина європейська`, `бук лісовий`, `дуб звичайний` | «хвойний ліс», «дерева» |
| `PRODUCT` | Деревинний або недеревинний продукт | `деревина ялини`, `дрова твердолистяних`, `білі гриби`, `чорниця` | «сировина», «продукція» |
| `THREAT` | Екологічна, біотична чи пожежна загроза | `короїд-типограф`, `верхова пожежа`, `вітровал`, `посуха` | «несприятливі умови», «ризик» |
| `ACTOR` | Відповідальна особа, бригада або служба | `Фомін О.В. (F-104)`, `Бригада №1 (BR-01)`, `ДСНС Львів` | «працівники», «лісгосп загалом» |

## 2. Типи відношень (6 типів, C1)

| Відношення | Сигнатура (`subject → object`) | Приклад із тексту | Контрприклад |
|---|---|---|---|
| `PART_OF` | `COMPARTMENT → FORESTRY` | «Виділ V-003 входить до лісництва LS-01» | Згадка лісництва в іншому реченні без прив’язки |
| `DOMINATED_BY` | `COMPARTMENT → SPECIES` | «На виділі V-012 переважає ялина європейська» | «Деревина ялини» (це продукт, не порода) |
| `YIELDS` | `COMPARTMENT → PRODUCT` | «Із виділу V-102 заготовлено деревину дуба» | Плановий намір без факту або дозволу |
| `AFFECTED_BY` | `COMPARTMENT → THREAT` | «На виділі V-014 зафіксовано осередок короїда-типографа» | «На V-003 пожеж не виявлено» (заперечення) |
| `SUPERVISES` | `ACTOR → COMPARTMENT` | «Лісник F-104 відповідає за моніторинг виділу V-003» | Згадка лісника без вказівки виділу |
| `MITIGATES` | `ACTOR → THREAT` | «ДСНС Львів локалізувала верхову пожежу» | Просте сповіщення без дії з ліквідації |

## 3. Інструкція розмітки: 7 правил і граничні випадки (C2)
1. **Правило точної цитати (`evidence`)**: кожне твердження повинно містити дослівну підстрічку вихідного документа з точними символьними офсетами `[start_offset, end_offset)`.
2. **Правило напрямленості**: `COMPARTMENT` завжди є суб’єктом у `PART_OF`, `DOMINATED_BY`, `YIELDS`, `AFFECTED_BY`; `ACTOR` завжди є суб’єктом у `SUPERVISES` і `MITIGATES`.
3. **Правило заперечень (граничний випадок)**: якщо у реченні є заперечення («не виявлено», «відсутній», «не зафіксовано»), відношення `AFFECTED_BY` або `YIELDS` **не створюється**.
4. **Правило гіпотетичності (граничний випадок)**: умовні/модальні згадки («у разі посухи можливий вітровал») не розмічаються як доконаний факт `AFFECTED_BY`.
5. **Правило розрізнення породи й продукту**: «ялина європейська» → `SPECIES` (`DOMINATED_BY`), тоді як «деревина ялини» → `PRODUCT` (`YIELDS`).
6. **Правило декомпозиції списків**: якщо одне речення перелічує кілька виділів або продуктів («на V-003 та V-012 виявлено короїда»), створюються окремі твердження для кожної пари.
7. **Правило канонізації**: у полях `subject` і `object` записуються нормалізовані форми (напр. `V-012`, `LS-01`, `ялина європейська`), а оригінальне формулювання зберігається в `evidence`.

## 4. JSON-схема виходу та правила нормалізації (C3)

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "type": "object",
  "required": ["doc_id", "claims"],
  "properties": {
    "doc_id": {"type": "string"},
    "claims": {
      "type": "array",
      "items": {
        "type": "object",
        "required": ["subject", "subject_type", "relation", "object", "object_type", "evidence", "start_offset", "end_offset", "confidence"],
        "properties": {
          "subject": {"type": "string"},
          "subject_type": {"enum": ["FORESTRY","COMPARTMENT","SPECIES","PRODUCT","THREAT","ACTOR"]},
          "relation": {"enum": ["PART_OF","DOMINATED_BY","YIELDS","AFFECTED_BY","SUPERVISES","MITIGATES"]},
          "object": {"type": "string"},
          "object_type": {"enum": ["FORESTRY","COMPARTMENT","SPECIES","PRODUCT","THREAT","ACTOR"]},
          "evidence": {"type": "string", "minLength": 10},
          "start_offset": {"type": "integer", "minimum": 0},
          "end_offset": {"type": "integer", "minimum": 1},
          "confidence": {"type": "number", "minimum": 0.0, "maximum": 1.0}
        }
      }
    }
  }
}
```

**Правила нормалізації**:
- Коди виділів і лісництв зводяться до верхнього регістру з дефісом: `виділ 12` / `V012` → `V-012`; `ЛС-1` → `LS-01`.
- Породи, продукти та загрози зводяться до називного відмінка однини/канонічної форми словника (`короїда-типографа` → `короїд-типограф`; `деревину бука` → `деревина бука`).
- Кожна канонічна сутність прив’язується до IRI у просторі `https://foresthub.ua/onto/`.

## 5. Результати пілотної розмітки 5 фрагментів та уточнення інструкції (C4)
На 5 пілотних фрагментах корпусу виявлено 3 розбіжності між розмітниками й внесено **3 уточнення інструкції** (вимога ≥ 2):
1. **Уточнення №1 (порода vs продукт)**: у фрагменті про `V-003` («заготівля деревини ялини») один розмітник поставив `DOMINATED_BY(V-003, ялина європейська)`. Зафіксовано Правило 5: словосполучення «деревина + порода» — завжди `PRODUCT` (`YIELDS`).
2. **Уточнення №2 (заперечення загроз)**: у фрагменті про `V-008` («ознак короїда-типографа не виявлено») зафіксовано Правило 3 про ігнорування заперечних конструкцій.
3. **Уточнення №3 (перелік виділів у реченні)**: у фрагменті про `LS-03` («виділи V-201 та V-203 обслуговує лісник F-301») зафіксовано Правило 6 щодо генерації двох окремих тверджень `SUPERVISES` з однаковим `evidence`.
